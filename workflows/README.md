# n8n Workflows

This folder contains the n8n workflows used in the AI Placement Preparation Agent.

## Workflows

### 1. Resume Feedback Agent
Automatically analyzes uploaded student resumes using Gemini AI and generates:
- ATS Score
- Strengths
- Weaknesses
- Missing Skills
- Suggestions
- Overall Feedback

### 2. AI Placement Preparation Agent
Uses the generated resume analysis and student data to provide personalized placement preparation recommendations.

## Technology
- n8n
- Gemini API
- Google Drive
- Google Sheets
- Gmail
- Docker
